# Python ATM

A simple console-based ATM simulation built with Python.

## Features

- PIN authentication
- Limited PIN attempts
- Check account balance
- Deposit money
- Withdraw money
- Exit the program
- Input validation

## Technologies Used

- Python 3

## How to Run

1. Install Python 3
2. Clone this repository
3. Open a terminal in the project folder
4. Run:

atmcode.py
